# ACP patch notes

- Причина падения ACP: парсер diff получил невалидную строку rename (`Moved to: ...`) и завершился с `Unknown line`.
- Для rename в `apply_patch` использовать только строгий формат:
  - `*** Update File: relative/path`
  - `*** Move to: relative/path`
- Не использовать абсолютные Windows-пути в patch. Только пути относительно репозитория.
- Не писать `Moved to:` без префикса `***`.
- Для путей с `[` и `]` в PowerShell использовать `-LiteralPath`, чтобы не поймать ошибки чтения/проверки.
- Не записывать текстовые файлы через путь, который может перекодировать UTF-8 в Windows code page. Для правок использовать `apply_patch`; при чтении/проверке в PowerShell явно задавать `-Encoding utf8`.
- Если в тексте появились последовательности вроде `Р...`, `Ð...`, `Ñ...`, считать это mojibake после неверной перекодировки и сразу исправлять до коммита.
- Для rename, если есть риск на стороне ACP, надёжнее сначала сделать `git mv` или `Move-Item`, а содержимое менять отдельным patch.
- После rename сразу проверять `git status`, чтобы не оставить состояние вида: старый файл deleted, новый untracked.
- Для Astro routes:
  - конкретная страница: `test-post.astro`
  - параметр: `[slug].astro`
  - catch-all: `[...slug].astro`
  - имя параметра внутри `[]` не должно содержать `-`
